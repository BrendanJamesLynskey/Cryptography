## Technology

[Reveal.js 4.6](https://revealjs.com) · [highlight.js](https://highlightjs.org) (Atom One Light) · Schibsted Grotesk + Azeret Mono

Code listings render at 17 px in the 900 px slide (about 14.5 px on a 1280×800 laptop) and scroll sideways rather than shrink. On a phone (≤ 640 px wide) slides are laid out at the phone's own width instead of being scaled down, so text and code stay readable; tall slides scroll vertically.
